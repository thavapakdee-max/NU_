วิธีใช้
- แตกไฟล์ zip แล้วเปิด index.html ด้วยเบราว์เซอร์ได้ทันที
- ต้องมีอินเทอร์เน็ตเพื่อโหลดฟอนต์ (IBM Plex Sans Thai / Noto Serif Thai) หากไม่มีจะใช้ฟอนต์สำรองของเครื่อง

แก้ไขข้อมูล
- รายการทุน/ประกาศอยู่ในตัวแปร data ที่ต้นไฟล์ script.js (title, cat, desc, tags, status, url)
- ค่า cat ใช้ได้: scholarship, research, conference, exchange, announcement, documents
- ลิงก์ทางลัดและลิงก์ท้ายหน้าแก้ได้ใน index.html
